# Security

Found a vulnerability in UTTT or at [uttt.org](https://uttt.org)? Please report it privately: on GitHub, open
the repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue for it.

We'll reply as soon as we can and credit you in the fix, if you'd like. Please don't access other players'
data or disrupt the site while testing: a local copy (see the README) is the place to try things.
